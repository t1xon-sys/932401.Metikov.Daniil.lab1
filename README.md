Тема: «Студент-разработчик»

Данная работа предстовляет собой ознакомление с базовой структурой HTML-документа,семантическими тегами, работой с текстом,
списками, ссылками и изображениями.

Я создал HTML-страницу "О себе", которая содержит строго определённые семантические элементы:(header), (main), секции (section) со списками, боковую панель (aside), подвал (footer), изображение с заданными атрибутами и форму обратной связи.
Структура HTML-документа:

1.(header) Шапка: Содержит имя студента «Метиков Даниил» и заголовок «Студент-разработчик»,Оформлена в синем цвете #1e5aa8 с белым текстом, Добавлены декоративные изображения (логотип факультета и картинка).
2.(main) Основной контент: Секция «Мой Аватар»: содержит личное изображение (портрет), Для тега img указаны все требуемые атрибуты: src, alt, width, height.  Секция «Навыки»: реализована с помощью маркированного списка ul. Перечислены языки и технологии. Секция «Проекты»: : реализована с помощью нумерованного списка ol. Перечислены 5 учебных проектов. (aside) Боковая панель : содержит краткую информацию о любимых инструментах имеет светло-голубой фон #e3efff для визуального отделения от основного контента. Секция «Обратная связь»: содержит форму (form) с полями: Имя,Email,Сообщение с атрибутами name и placeholder и Кнопка отправки.
3.(footer) Подвал:  Содержит информацию об авторском праве и год, Стилизована в едином цвете с шапкой страницы.

Согласно заданию, использована сине-белая палитра: Основной фон страницы: светло-голубой,  Шапка, подвал и заголовки секций: насыщенный синий, Основной контент и боковая панель: белый, Основной текст: тёмно-серый/чёрный
